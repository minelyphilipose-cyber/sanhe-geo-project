落地建议

先做通用视觉规则，再替换典型列表和详情页，避免每个页面单独美化。

1. 白色容器要有层次

页面背景用浅灰，卡片用白色，重点卡片加轻阴影，表格保留白底但增加顶部摘要区。

2. 状态必须可视化

状态不要只靠文字，统一使用颜色标签、进度条、风险条、时间线节点。

3. 列表要有实体感

品牌、客户、项目用首字头像或图标块，搭配副文本，让每行不再像纯文本堆叠。

4. 详情先给结论

详情页顶部放对象、状态、关键指标和主要操作，再进入明细、记录、配置。
