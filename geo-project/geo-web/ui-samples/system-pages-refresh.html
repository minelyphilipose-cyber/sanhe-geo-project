四、系统级落地规则

这套规则先做成通用样式/组件，再逐页替换，避免每个页面单独美化。

列表页统一结构

页面标题、筛选条、摘要指标、业务表格、分页区，所有管理页保持一致。

详情页对象化

顶部 hero 展示对象身份和关键指标，右侧保留上下文摘要，主体用分组卡片承载信息。

表单页分组化

长表单拆为基础信息、业务配置、额度范围、预览确认，减少用户压迫感。

状态组件统一

完成、生成中、失败、待处理、冻结、降级、未启用等状态使用统一色彩和标签。
