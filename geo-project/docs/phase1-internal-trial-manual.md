# GEO 内部交付系统 Phase 1 试跑手册

## 1. 目标范围
本手册用于内部试跑 Phase 1，验证三条最小可用链路：
- 合伙人管理 + 充值录入
- 客户录入 + 品牌录入
- 项目录入 + 状态阶段推进

## 2. 账号准备
- 内部管理员账号：可创建和编辑数据
- 合伙人账号：只读验证（不可新增/修改）

## 3. 启动步骤
1. 启动 MySQL / Redis / MinIO（docker-compose）
2. 启动 geo-server（Spring Boot）
3. 启动 geo-web（npm run dev）
4. 打开后台 `/login`

## 4. 试跑场景 A：合伙人链路
1. 进入 `管理后台 -> 合伙人管理`
2. 点击“新建合伙人”，填写：
- 编号（如 `hz_sh_001`）
- 名称
- 等级
- 折扣率
3. 保存后自动跳转到合伙人详情
4. 在“虚拟账户”执行“充值录入”
5. 检查：
- 当前余额增加
- 累计充值增加
- 流水新增且余额前后正确
6. 执行“手工调整”（可正可负）
7. 检查流水与余额变化一致

验收标准：
- 充值与调整均可成功
- 列表刷新后数据一致
- 详情页余额与流水一致

## 5. 试跑场景 B：客户与品牌链路
1. 进入 `管理后台 -> 客户管理`
2. 点击“新建客户”，填写：
- 公司名称
- 归属类型（direct/partner/joint）
- 若 partner/joint，必须填写合伙人ID
3. 保存后自动跳转客户详情
4. 在客户详情点击“新增品牌”，填写：
- 品牌名称
- 品牌标识（小写字母数字开头，可含 `_` `-`）
5. 保存后检查品牌列表刷新
6. 点击“编辑品牌”修改业务字段后再次保存

验收标准：
- 客户可创建并可回查
- 品牌可创建、可编辑
- slug 校验生效

## 6. 试跑场景 C：项目链路
1. 可从“客户详情 -> 基于该品牌建项目”进入，或直接进入项目管理
2. 点击“新建项目”，填写：
- 项目名称
- 品牌
- 套餐（自动带出价格和月数，可手改）
- 归属类型（partner/joint 时需填写合伙人ID）
3. 保存后自动跳转项目详情
4. 在项目详情修改“状态”和“阶段”并保存
5. 刷新页面确认状态保持一致

验收标准：
- 项目可创建、可编辑
- 状态与阶段可更新且刷新后一致

## 7. 异常与排查
- Flyway 启动失败（V2 failed）：先修复 flyway_schema_history 的失败记录，再重启
- 保存失败：检查必填字段、ownerType 与 partnerId 配置
- 合伙人账号无法修改：属于 Phase 1 设计约束（只读）

## 8. 建议试跑记录模板
每条链路记录以下内容：
- 测试人
- 操作时间
- 输入样例
- 实际结果
- 是否通过
- 问题截图 / 接口报错

## 9. Phase 1 已知边界
- 仅内部后台可操作，终端客户不登录
- 报表实例、分享发布、PDF、自动发布拦截不在本阶段
- 签约自动扣款在第 4 步实现
