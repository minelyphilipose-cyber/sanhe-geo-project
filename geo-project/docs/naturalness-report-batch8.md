## 4 个根因详细分析

### 根因 1:brand.suffix"品类语义后缀"与品牌名核心词冲突(brand 13 条不合格里 8 条)

PRD 3.1.5 期望的 brand 后缀分了"了解类/评价类/归属类"3 类共 15 词。其中部分词假设核心词是**品类**,但用户实际输入是**具体品牌名**:

| 后缀(词库) | 与品牌名核心词搭配后的关键词 | 问题 |
|------------|----------------------------|------|
| 老牌子有哪些 | 华为老牌子有哪些 / 海底捞老牌子有哪些 | 已给品牌还问"老牌子有哪些"逻辑不通 |
| 品牌有哪些   | 蓝凌品牌有哪些                       | 同上 |
| 是什么       | 华为公司是什么 / 海底捞品牌是什么     | 已知品牌问"是什么"语义错位 |
| 是什么牌子   | (类似)                              | 同上 |
| 有名吗       | (类似)                              | 同上 |

**修复**:下架这 5 条 brand.suffix。

### 根因 2:transaction.industry "商品"对 SaaS 品牌措辞不准(transaction 7 条不合格里 5 条)

| 行 | 问题关键词 |
|---|---|
| 17 | 打折的钉钉商品收费标准 |
| 48 | 实惠的金蝶商品怎么收费 |
| 49 | 便宜的飞书商品收费标准 |
| 50 | 实惠的金蝶商品报价单 |
| 64 | 北京实惠的钉钉商品收费标准 |

中文"商品"暗指**实物**,SaaS 应说"产品/服务/方案"。

**修复**:下架 transaction.industry "商品"(id=196)。

### 根因 3:qa.prefix"国产/进口/新款/最新款"与具体品牌核心词冲突(qa 9 条不合格里 5 条)

| 关键词 | 问题 |
|--------|------|
| 国产小米安装方法 / 国产小米怎么用 / 国产小米怎么保养 | "国产小米"冗余,小米本身国产 |
| 国产用友安装方法                                       | "国产用友"冗余,用友本身国产 |
| 进口小米安装方法 / 进口小米怎么用 / 进口金蝶怎么用     | 小米/金蝶非"进口" |

**修复**:下架 qa.prefix 的"进口/国产/新款/最新款" 4 条(保留"高品质"——它对具体品牌也成立"高品质小米使用方法")。

### 根因 4:comparison.compare "比较"作连接词不自然(comparison 6 条不合格里 2 条)

`苹果比较华为哪个更好` / `小米比较三星有什么不同` —— 中文里"A 比较 B"不如"A 对比 B"自然。

**修复**:下架 comparison.compare "比较"。

### 附加根因 5:brand.prefix"排名前十的"对具体品牌逻辑不通(brand 13 条不合格里 3 条)

`排名前十的华为厂家品牌有哪些` —— 华为是单一品牌,谈"排名前十的华为"逻辑不通。

**修复**:下架 brand.prefix "排名前十的"(id=295)。

### 评估方法层(下次评估优化)

抽样核心词清单应**50% 品类词 + 50% 品牌词**:

```
toC 品牌:小米 / 华为 / 苹果 / 海底捞 / 星巴克 (5)
toB 品牌:钉钉 / 飞书 / 用友 / 金蝶 / 蓝凌 (5)
toC 品类:手机 / 笔记本 / 汽车 / 冰箱 / 西装 (5)  ← 新增
toB 品类:OA 软件 / CRM / ERP / BI / 协作工具 (5)  ← 新增
```

每个 type 抽样时混合品牌+品类核心词,确保两种场景都覆盖。
