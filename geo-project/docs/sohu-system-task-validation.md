## 实现

- 注册搜狐后台延迟执行适配：到时执行即时发布，不依赖平台原生定时功能。
- 扩展根据系统排期启用自动提交，填充前核对账号，设置 AI 声明，提交前持久保存任务尝试记录，跨标签页及扩展重启不重放提交。
- 审核中表示已提交，保持结果回查队列；只有匹配账号、标题、文章 ID 及搜狐公开链接才确认发布。
- 审核拒绝关闭关联任务并按原额度流水退回；提交结果不明只回查，不自动重新发文。
- 本地助手重新按现有配对流程绑定，浏览器环境重新绑定至该助手；签名校验保留，修复手动领取接口读取请求正文的顺序。
- 失败后恢复原排期时，重新占用已退回的原额度流水；通过数据库条件更新避免并发重复计数。重复确认同一公开链接不会新增发布记录或再次计数。
- 修复排期成功后空字段未写入数据库的问题，清除旧失败提示与下次执行时间。
- 正文图片按原文位置逐张通过搜狐本地上传窗口转存；核对图片地址、加载状态、正文数量。上传未确认或今日剩余额度未确认时阻止自动提交；每张支持不超过10MB的 JPG、PNG、GIF。初始版本要求正文至少一张插图，现已按用户确认规则放开无图发布，详见后续生成规则。
