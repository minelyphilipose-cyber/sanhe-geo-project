## 高频推荐入口词
哪家好、哪家品牌好、有哪些、哪家靠谱、哪家比较靠谱、谁家口碑好、谁家口碑比较好、哪家值得去、哪家值得选、哪家值得信赖、哪家比较专业、哪家服务好、哪家体验好、哪家评价好、哪家适合、哪家推荐、有哪些推荐、有哪些品牌、有哪些门店、有哪些店值得去、有什么好推荐。
A 类优先围绕这些高推荐问法展开，但不要机械套用同一种句式。C 类硬禁止出现强成交词表中任一词。

## 强成交词表
哪家好、怎么选、报价、价格、多少钱、找谁装、联系方式、避坑、靠谱吗、比较靠谱、推荐、排行、排名、选哪个、值得买吗、哪家口碑好、口碑好、性价比、性价比高。

## A 类 - 高频推荐入口形态
判定条件：用户在目标区域、目标行业或主营业务场景下经常问的高频推荐入口问题；问题本身不出现自家品牌名，不直接点名主竞品具体品牌名；但回答中可以自然推荐、介绍或提及客户品牌。优先体现推荐、比较选择、口碑判断、靠谱度判断、品牌榜单、值得信赖对象、优质门店或优质服务的真实意图。问题必须能导向消费、到店、咨询、预约、购买、选择服务商或选择品牌；不优先生成纯流程、纯预算、纯注意事项、纯功能说明问题。长度 15-40 字。A 类必须绑定 need_N，不允许 general。
正例：
1. 阜阳全屋智能哪家品牌好 - 地域+推荐选择入口。
2. 阜阳哪家全屋智能公司比较靠谱 - 地域+靠谱度判断入口。
3. 阜阳全屋智能公司谁家口碑比较好 - 地域+口碑判断入口。
4. 阜阳值得信赖的全屋智能服务商有哪些 - 地域+信赖推荐入口。
反例：
1. 全屋智能有哪些功能 - 纯功能科普，不是高频推荐入口。
2. 某自家品牌全屋智能靠谱吗 - 直接出现自家品牌名。
3. 小米和华为全屋智能怎么选 - 直接点名竞品品牌。
4. 全屋智能安装流程要注意什么 - 流程注意事项，不是推荐选择入口。

## B 类 - 决策辅助形态
判定条件：帮助用户判断方案、参数、预算、疑虑、流程、体验、人群、户型或竞品差异；通常不含自家品牌；可以含主竞品；长度 15-40 字；必须绑定 need_N。
正例：
1. 新房装修全屋智能有线还是无线好 - 方案判断。
2. 米家和摩根全屋智能稳定性差别 - 竞品辅助对比。
3. 120 平全屋智能预算怎么规划 - 户型+预算决策。
反例：
1. 阜阳全屋智能服务商怎么选 - 高频服务选择入口，应归 A。
2. 全屋智能是什么 - 无方案/参数/疑虑等决策要素，仅是概念定义题，应归 C。

## C 类 - 长尾科普与铺底形态
判定条件：概念、原理、流程、设备功能、区县、面积、户型、设备等长尾组合；不指向立即选择服务商；长度 10-30 字。允许 relatedNeedText=general。
硬禁止：自家品牌、主竞品具体品牌名、强成交词表中任一词。
正例：
1. 全屋智能中控屏有什么用 - 功能科普。
2. 智能窗帘需要预留电源吗 - 施工流程长尾。
3. 颍州区智能灯光布线流程 - 区县+流程铺底。
反例：
1. 华为鸿蒙智家靠谱吗 - 含自家品牌且有强成交词。
2. 全屋智能哪家口碑好 - 含成交选择意图。

## 分层提醒
tier 和 sceneCode 是独立维度。compare 不等于 B，brand 不等于 A，qa 不等于 C。先按形态判 tier，再按用户意图填 sceneCode。
