## 品牌匹配
selfBrandTerms 仅以 brand_name 完整字符串为准，不拆子串。company_name 不单独参与品牌名命中判断。
请严格控制含 selfBrandTerms 题量：A=0%，B≤15%，C=0%，整体≤25%。

## 输出要求
输出严格 JSON 数组。A/B/C 数量必须分别精确等于 a_count/b_count/c_count。
每个元素只能包含 questionText、tier、sceneCode、relatedNeedText、designReason。
不得输出 priority、monitorFrequency、score*、totalScore。
